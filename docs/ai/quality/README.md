# AI品質ベンチマーク

Issue #15で、対局AIと棋譜解析を感覚ではなく固定局面で比較するための記録。

## 実行方法

```sh
npm run benchmark:ai
```

正本は次の3か所とする。

- `src/engine/ai-benchmark.ts`: 実行可能な局面・許容手・プロファイル
- `benchmark-cases.csv`: 人がレビューしやすいケース一覧
- `benchmark-results.csv`: 変更前後の試行結果

## 結果

| run | tactical | opening/play | total |
|---|---:|---:|---:|
| BASELINE-001 | 8 / 8 | 10 / 20 | 18 / 28 (64.3%) |
| IMPROVED-001 | 8 / 8 | 20 / 20 | 28 / 28 (100%) |

BASELINE-001では、AI初級の120点ランダム幅により、同じ序盤局面でも金・飛車・玉の不自然な早動きが選ばれた。また`randomness: 0`の解析でも、同点候補を`Math.random()`で選んでいたため、初期局面に対して5つの乱数標本から5種類の手を返した。

IMPROVED-001では、初級以上のランダム幅をなくし、解析の同点時も先頭の最善候補を決定的に選ぶ。序盤4局面を5つの乱数標本で再実行しても、各局面で同じ許容手を返した。

初期局面を最大深さ5・1200msで探索した効率比較では、置換表なしが220,416ノードで深さ4まで（1202ms）だったのに対し、置換表ありは121,363ノード・1,384ヒットで深さ5を完了した（719ms）。同じ時間枠で1段深く探索できた。

## 変更した探索条件

| profile | before | after |
|---|---|---|
| AI入門 | depth 1 / 500ms / randomness 350 | 変更なし |
| AI初級 | depth 2 / 1000ms / randomness 120 | depth 3 / 1200ms / randomness 0 |
| AI中級 | depth 3 / 2500ms | depth 4 / 2500ms |
| AI上級 | depth 5 / 5000ms | 変更なし |
| 棋譜解析 | depth 4 / 800ms per position | depth 5 / 1200ms per position |

## 改善内容

- 王手中の静止探索ではstand-patせず、捕獲以外も含む合法応手を読む。
- 置換表で同一局面の評価と最善手を再利用し、反復深化の指し手順序へ使う。
- タイムアウト時も`finally`で指し手を戻し、入力局面を破壊しない。
- 駒の前進、飛角の可動域、飛車の配置、玉周辺の守備駒を評価へ追加する。
- 対局レベル設定と解析設定を`levelToOptions`／`analysisOptions`へ分離する。

## 解釈上の制約

このベンチマークは、明白な戦術と序盤の不自然手を検知する内部回帰テストである。プロ棋士水準、段級位、YaneuraOu等の専用エンジンとの評価値一致は保証しない。局面数を増やす場合は、許容手の根拠を人間または外部エンジンでレビューする。

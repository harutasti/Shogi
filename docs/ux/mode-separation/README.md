# 対局／解析 情報分離 Discovery

GitHub Issue #9「対局とAI解析の情報分離で操作負荷を下げられるか」を検証するための資料を管理する。

このディレクトリは実装仕様ではない。現行版のベースライン、比較プロトタイプ、初見ユーザーテストの結果から、変更するか現状を維持するかを判断するための記録である。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `test-plan.md` | 仮説、対象者、共通手順、評価方法、判断ゲート |
| `scenarios.csv` | 全案で共通利用するタスクシナリオ |
| `baseline.csv` | 現行公開版の測定結果。自動操作と人間テストを区別する |
| `prototype-results.csv` | 比較プロトタイプの測定結果 |
| `decision.md` | 結果の要約、トレードオフ、採用判断 |
| `UX_Mode_Separation_Discovery_Tracker.xlsx` | CSVを閲覧・入力しやすくした操作用台帳 |

CSVをレビューと履歴確認の正本とする。Excelを更新した場合は、同じ変更内容を対応するCSVにも反映する。

## 重要な区別

- **Computer Useベンチマーク**: 画面到達性、必要操作数、スクロール、状態遷移、回帰を一貫した手順で比較する。
- **初見ユーザーテスト**: 発見性、理解、迷い、安心感を人間の観察と発話から確認する。

Computer Useの成功を、人間が迷わないことの証明として扱わない。
